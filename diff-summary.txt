PURPOSE AND BEHAVIOUR
- Dynamically add Browse beside the existing Location input and map-search button.
- Dynamically create a modal using the site's existing button and modal classes.
- Expand countries to choose a city or all results in that country.
- Read the already loaded venue/event arrays; do not fetch replacement data.
- Prefer public-venue city/country pairs over conflicting event country spellings.
- Use reliable non-broad events for cities without a venue country source.
- Exclude broad labels and multi-country labels from country rows. Ignore cities
  that have no reliable country source; no Europe country group is created.
- Count through the existing Results functions and honour retained type/tag filters.
  The typed query is excluded because the existing saveLocation clears it.
- Selecting Prague sets loc-location to "Prague, Czechia", closes Browse and calls
  the unchanged saveLocation(). Country selection saves the existing country scope.
- Preserve existing matching behaviour: no additional broad-region event matches
  are invented. Prague, Czechia matches the Results page's 30 results on test date.
- Close button, Escape, backdrop dismissal and keyboard focus handling are local
  to the new modal.
